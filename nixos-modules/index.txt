NixOS modules; basename = the name used in `with ezModules; [...]`.

default.nix           Implicit host module: core imports (home-manager, agenix, stylix, overlays, shared modules).
base.nix              System baseline: networking, audio, printing, session secrets and packages.
gnome.nix             GNOME apps. Kept for reference; no host imports it now.
kde.nix               Plasma desktop session; the greeter stays the login manager.
noctalia.nix          Global display session, greeter and Stylix-themed login screen.
gaming.nix            Gaming.
laptop.nix            Power management and the power-profile interface for Noctalia.
containers.nix        Container tooling; imports the platform split.
containers-linux.nix  Linux container runtime and networking.
containers-darwin.nix macOS container runtime and context.
boot.nix              Boot UI, bootloader/Secure Boot choice and optional TPM2 unlock.
