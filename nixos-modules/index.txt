NixOS modules; basename = the name used in `with ezModules; [...]`.

default.nix            Implicit host module: imports home-manager, agenix, stylix,
                       freetoken, ../overlays, ../shared-modules/*.
base.nix                Core baseline: imports the .system variant of the shared
                       Bosque theme from themes/bosque-kingdoms.nix, X11, NetworkManager,
                       bluetooth, pipewire, firewall, tailnet-only sshd, printers,
                       system packages; shadows blueman's XDG autostart entry so
                       its applet only starts with Hyprland.
gnome.nix               GNOME apps disabled (no GNOME shell session); core apps,
                       dev tools and games stay off. Kept for reference; no
                       host imports it now.
kde.nix                 Plasma 6 desktop session. GDM and SDDM stay off so the
                       greetd/noctalia greeter remains the login manager.
noctalia.nix            Global display session: noctalia-greeter, Umbriel + portal,
                       Noctalia binary + recommended services (UPower for the
                       battery widget), and greeter palette/font/dark mode/
                       wallpaper taken from the shared Stylix config.
gaming.nix              gamescope + gamemode.
laptop.nix              TLP power/charge thresholds + PPD-compatible DBus interface
                        for Noctalia's power-profile widget.
containers.nix          Container tooling; imports the linux + darwin split.
containers-linux.nix    Linux: podman containers, docker, trusts docker0.
containers-darwin.nix   macOS: colima + docker, DOCKER_CONTEXT=colima.
boot.nix                Imported by default. Boot UI (plymouth, quiet params),
                        systemd-boot vs Lanzaboote switch, optional
                        systemd-pcrlock TPM2 unlock for listed LUKS devices.
                        Adds secure-boot-enroll.
