One file per home-manager user. Host assignment is in flake.nix; each user
selects the .user variant of a theme. Git identity comes from config.sensitive
(secrets/ - never read).

adam.nix   Home-manager settings, theme and installed programs for user adam,
           including both desktop stacks and development tooling.
mirj.nix   Home-manager settings, theme and installed programs for user mirj,
           including the Plasma desktop and graphics tooling.
games.nix  Home-manager settings, theme and installed programs for user games,
           including the Plasma desktop and gaming.
work.nix   Home-manager settings, theme and installed programs for user work,
           including development tooling and work-specific services.
