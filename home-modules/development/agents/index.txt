Jailed/free opencode agent setup.

default.nix   Home-manager options, llm-agents packages (rtk, herdr,
              opencode), herdr-auth-proxy/herdr-auth, the shared agent package
              list, the Collie plugin path and the rtk shell.
policy.nix    Local policy: secrets/gh token, CUDA, Nix daemon, jail
              permissions, opencode allowAllReads (v2 permissions array),
              Herdr plugin, auth-socket-only Herdr access with a
              directory/workspace-scoped orchestrator token that replaces the
              inherited bootstrap token and raises its agent_grants to
              report_status, read_own_pane and wait_own_output, the Collie
              plugin and shared Collie socket, and the free/jailed variants.
              Uses agent-toolbox for generic jail and env forwarding.
opencode.nix opencode defaults + wrapper: v2 config (FreeToken provider,
              rtk shell, serena MCP), bakes OPENCODE_CONFIG, maps TUI --agent
              to OPENCODE_CONFIG_CONTENT, and keeps the server private to the
              jail run.
launcher.nix  Wrapper that runs the agent through the project's direnv/dev
              shell when a .envrc is present, then execs the prebuilt jailed
              package. No runtime Nix evaluation.
