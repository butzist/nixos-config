Home-manager modules; basename = the name used in `with ezModules; [...]`.
default.nix is the implicit module of every user.

default.nix   Core imports (agenix, nvf, stylix, overlays) and user secrets.
base.nix      User baseline: shell packages, aliases and the session secret service (gnome-keyring).
nushell.nix   Shell environment and prompt/completion tooling.
zellij.nix    Terminal multiplexer keymap and startup mode.
kitty.nix     Terminal appearance and keybindings.
wezterm.nix   Terminal. Unused; kitty is the one in use.
kde.nix       Plasma desktop theming and KDE Connect.
hyprland.nix  Hyprland desktop: theming, keybinds, lock/idle/wallpaper and autostart.
walker.nix    Application launcher with inline Stylix theming.
wlogout.nix   Logout menu with inline Stylix theming.
gaming.nix    Gaming.
office.nix    Office, graphics and dictionary packages.
rofi.nix      Rofi. Unused; walker is the launcher in use.
development/  Development packages, git settings and jailed agents (see index.txt).
waybar/       Status bar (see index.txt).
noctalia.nix  Noctalia/Umbriel desktop shell: theming, keybinds and autostart.
neovim/       Neovim via nvf (see index.txt).
work/         Work-only modules (see index.txt).
